# Sound board files

This folder already includes public-domain recordings for the air horn, crowd cheer, crickets, drumroll, sad trombone and fight bell (see `CREDITS.md`). Replace any of them by uploading a file with the same name.

Put MP3 files in this folder with these exact names and the sound board will use them automatically. Any file that's missing falls back to the built-in sound.

| File name | Sound board button | Key |
|---|---|---|
| `airhorn.mp3` | Air horn | 5 |
| `cheer.mp3` | Crowd cheer | 6 |
| `crickets.mp3` | Crickets | 7 |
| `drumroll.mp3` | Drumroll | 8 |
| `trombone.mp3` | Sad trombone | 9 |
| `bell.mp3` | Fight bell | 0 |

Keep each clip short (a few seconds) and under about 1 MB.

To add a file from the GitHub website: open this `sounds` folder, choose **Add file → Upload files**, drag the MP3 in, and commit.

## Other sounds used by the tool

These play automatically at certain moments. Replace any of them by uploading a file with the same name.

| File name | When it plays |
|---|---|
| `tada.mp3` | A winner is picked, the wheel lands, an award is revealed (plus `cheer.mp3` for the champion) |
| `buzzer.mp3` | The battle timer runs out |
| `countdown.mp3` | The 3-2-1 FIGHT! countdown (beeps one second apart); `bell.mp3` rings on FIGHT! |
| `scratch.mp3` | A rematch is logged |
| `ding.mp3` | Randomize finishes ("Spots locked in!") |
| `whoosh.mp3` | Each highlight reel slide |

The walk-out intros use `bell.mp3` for each bot and `airhorn.mp3` for the face-off.
