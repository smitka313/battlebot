# Battle Bot Bracket

A single-elimination tournament bracket for a mechatronics battle bot tournament, built to run on a classroom smartboard.

Open `index.html` in any modern browser. It's one self-contained file and needs no install or server.

## Features

- **Roster:** enter bot code names and student names, edit them anytime, paste a list, or import a CSV (column F = first name, G = last name, H = bot name; students sharing a bot name become one team).
- **Automatic bracket:** sizes itself to the number of bots and gives byes to the top seeds.
- **Dramatic randomize:** shuffles the starting spots on screen several times and stops at a random point.
- **Battle screen:** click any battle to enlarge it, with red and blue corners. Tap the winner to advance them, with a fanfare and confetti.
- **Walk-out intros** with random strange "fun facts," a 3-2-1 FIGHT! countdown, and a battle timer.
- **How they won:** balloon pop, pushed out by opponent, forfeit, or left arena due to user error.
- **Rematch / no contest** logging, a 3rd-place battle, an on-deck panel, undo, and keyboard shortcuts.
- **Announcer calls** on every win, **farewell cards** for eliminated bots, and a **sound board** (air horn, crowd cheer, ooooh, drumroll, sad trombone, fight bell).
- **Sudden death:** a 30-second overtime when the timer runs out.
- **Superlative awards** at the end (Balloon Assassin, The Bulldozer, Giant Slayer, Ice in Their Veins, Most Dramatic, Luckiest Bot Alive, plus a mystery award).
- **Results and team stats** that copy straight into a spreadsheet or gradebook.
- **Saving:** progress saves automatically in the browser. Use **Save / load** to move a tournament to another computer.

## Keyboard shortcuts (battle screen)

| Key | Action |
|---|---|
| ← / R | Red corner wins |
| → / B | Blue corner wins |
| 1–4 | How they won |
| Space | Start/pause timer |
| I | Walk-out intros |
| N | Next battle |
| U or Ctrl+Z | Undo |
| 5–0 | Sound board effects |
| Esc | Close |
